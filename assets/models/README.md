# Self-authored 3D assets

All assets here are hand-authored Wavefront OBJ files: `agent_marker.obj`, `exit_door.obj`, `exit_key.obj`, `electrical_hazard.obj`, `water_flask.obj`, `ration_pack.obj`, and `caretaker_npc.obj`. They are intended for a future renderer and are not required by the V1 2D observer, per the project brief's constraint against adding a heavy 3D engine.
